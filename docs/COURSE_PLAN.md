# 16课研发文档智能知识库 Agent 课程总纲

2026-11-06～2026-11-21（北京时间）。每天一课，本地Python、Windows PowerShell、Conda py312，不用Docker；未实测指标绝不编造。每日八段邮件。

| 日期 | Day | 主题 | 当日可见成果 |
|---|---|---|---|
| 11/06 | 01 | 关键词检索与真实模型问答 | 终端提问→查本地Markdown→展示来源→DeepSeek回答；新增自己的知识文档 |
| 11/07 | 02 | 文档加载与来源元信息 | 支持多份.md/.txt文档，展示来源和文件名，增强索引输入 |
| 11/08 | 03 | 分块与重叠 | 给长文档按标题/段落切块，显示块ID和实际命中片段 |
| 11/09 | 04 | Embedding与语义相似度 | 在同一问题上对照关键词vs向量相似度，用本地轻量模型 |
| 11/10 | 05 | Chroma索引与知识库更新 | 落盘索引、重新打开不重复导入、文件更新后重建 |
| 11/11 | 06 | 证据引用与拒答 | 返回来源片段，资料不足拒答，避免无依据补全 |
| 11/12 | 07 | Streamlit可视化问答 | 网页输入、文档加载状态、来源证据展示 |
| 11/13 | 08 | 20题固定检索评测 | 建立Gold集合，对比关键词与向量检索Hit@K |
| 11/14 | 09 | BM25与向量混合检索 | 同题比较BM25、向量、融合排序，记录失败案例 |
| 11/15 | 10 | Rerank重排与兜底 | 对候选资料做重排，比较命中变化及性能成本 |
| 11/16 | 11 | LangGraph条件路由 | 把已有检索与回答函数包进最小状态图，观察节点路径 |
| 11/17 | 12 | Agent工具调用与信任边界 | 提供检索/查看资料工具，让模型选择工具并经执行器校验 |
| 11/18 | 13 | 多轮追问与上下文管理 | 历史问题改写、会话状态和上下文预算 |
| 11/19 | 14 | 错误分流与可观测Trace | 超时、空结果、非法参数、调用次数限制与Token记录 |
| 11/20 | 15 | FastAPI服务与基本回归 | 问答HTTP API、请求/响应校验、本地接口联调 |
| 11/21 | 16 | 综合验收与GitHub简历交付 | 30条评测、Badcases、README、架构图、演示与面试答辩 |

## 完成分界
Day 1~7：能演示的知识库问答；Day 8~10：检索评测/优化；Day 11~14：可解释的Agent工具和流程；Day 15~16：服务与求职展示。学习不顺可以放慢，所有真实掌握以个人日志为准。
